# 🚀 Open Budget Automation API

Ochiq Budjet (Open Budget) loyihalarida ovoz yigʻish jarayonini toʻliq avtomatlashtirish, tezlashtirish va oson boshqarish uchun maxsus ishlab chiqilgan yuqori tezlikdagi API yechimi.

---

### ⚡️ Asosiy Imkoniyatlar

* **Toʻliq Avtomatizatsiya:** SMS orqali tasdiqlash va ovoz berish jarayonini minimal kechikish bilan bajarish.
* **Yuqori Tezlik:** Koʻp oqimli (asinxron) arxitektura orqali soniyasiga oʻnlab soʻrovlarni qayta ishlash.
* **Oson Integratsiya:** Telegram botlar, veb-saytlar va boshqa xizmatlarga tezda ulash uchun qulay RESTful API endpoints.
* **Xavfsizlik va Barqarorlik:** Blokirovkalar va cheklovlardan himoyalangan barqaror soʻrovlar tizimi.
* **Batafsil Statistika:** Muvaffaqiyatli va muvaffaqiyatsiz ovozlarni real vaqtda monitoring qilish.

---

### 🎯 Kimlar Uchun?

* Ovoz yigʻish xizmatlarini koʻrsatuvchi tadbirkorlar va platformalar.
* Oʻz loyihasini tez va kafolatli gʻolib qilmoqchi boʻlgan tashabbuskorlar.
* Telegram bot yoki avtomatlashtirilgan ovoz berish panellarini ishlab chiquvchi dasturchilar.
